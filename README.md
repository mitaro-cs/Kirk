# Kirk

Остров сверху экрана для **macOS и Windows**: лимиты Claude Code и Codex, музыка и **Campus** – пары,
дедлайны и уведомления группы. На MacBook с чёлкой остров обнимает чёлку, на Windows и внешних мониторах –
аккуратная «пилюля» по центру.

## Что умеет

| Модуль     | Закрытый остров                                                              | Открытый остров                                                        |
| ---------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Лимиты** | кольца остатка Claude Code и Codex                                           | дуги окон «5 ч» и «Неделя», время сброса, цвет – темп расхода          |
| **Музыка** | обложка и эквалайзер                                                         | трек, позиция, пауза, следующий/предыдущий                             |
| **Campus** | время следующей пары или сколько до конца текущей, точка – новые уведомления | текущая/следующая пара, дедлайны с отметкой «сделано», переход на сайт |

- Новое уведомление Campus **всплывает** в острове на 6 секунд (щелчок – открыть на сайте).
- Открытие – наведением, щелчком или `Control+Alt+K` (меняется в настройках).
- Остров не забирает фокус: печатаете дальше, щёлкнув по нему.

## Campus

Настройки → Campus: адрес сайта и 6 цифр из Campus («Профиль → Безопасность → Показать код»). Сессия хранится
в связке ключей macOS / диспетчере учётных данных Windows. Kirk опрашивает `GET /api/live/seq` (раз в 5 с при
открытом острове, иначе раз в 15 с) и перечитывает «Сегодня» и уведомления, только когда на сайте что-то
изменилось.

## Лимиты

- **Claude Code** – Настройки → «Подключить»: Kirk ставит мост `kirk-bridge` в строку состояния
  (`~/.claude/settings.json`). Мост сохраняет только проценты и время сброса; прежняя строка состояния
  продолжает работать. Данные приходят после следующего ответа Claude Code.
- **Codex** – Kirk запускает свой `codex app-server` и только читает лимиты (`codex login` – ваш).

## Установка

Скачайте из [выпусков](https://github.com/mitaro-cs/Kirk/releases): `.dmg` (Apple Silicon или Intel) или
установщик `.exe` для Windows. Сборки пока без нотаризации Apple и подписи Windows:

- macOS – при первом запуске «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»;
- Windows – SmartScreen: «Подробнее → Выполнить в любом случае».

## Сборка

Нужны Rust (stable), Node 22+; на Linux – WebKitGTK (см. `.github/workflows/ci.yml`).

```sh
npm ci
npm run tauri dev       # приложение из исходников
npm run tauri build     # установщик для этой системы
cargo test --workspace  # тесты ядра
```

Музыка на Mac: из коробки – Music и Spotify (системные уведомления). Для любых плееров положите исходники
[mediaremote-adapter](https://github.com/ungive/mediaremote-adapter) в `vendor/mediaremote-adapter`
(например, git-подмодулем) – `scripts/prepare.mjs` соберёт и встроит его сам.

## Устройство

```
crates/kirk-core    логика без окон: лимиты, мост, Codex JSON-RPC, Campus, музыка, геометрия (тесты)
crates/kirk-bridge  мост строки состояния Claude Code
src-tauri           оболочка Tauri 2: окно-остров, трей, службы, платформенный код (mac/win)
src                 интерфейс на Svelte 5: остров и настройки
```

Идея – [CapaTheNotch](https://github.com/maximfakel/capa-the-notch) (MIT); Kirk написан с нуля и работает
на Mac и Windows. Лицензия – MIT.
