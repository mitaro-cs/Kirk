# Изменения

## 0.1.0

- Остров сверху экрана на macOS (с чёлкой и без) и Windows: открытие наведением, щелчком, `Control+Alt+K`;
  не забирает фокус.
- Лимиты Claude Code (мост строки состояния) и Codex (`codex app-server`, только чтение).
- Музыка: Windows – любой плеер системы; macOS – Music и Spotify, с mediaremote-adapter – любой.
- Campus: вход кодом, текущая и следующая пара, дедлайны с отметкой «сделано», переходы на сайт,
  счётчик и всплывание новых уведомлений.
- Настройки, значок в строке меню / области уведомлений, автозапуск.
